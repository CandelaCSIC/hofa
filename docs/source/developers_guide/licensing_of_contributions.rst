Licensing of Contributions
============================================================

.. toctree::

Contributions to this project are made through pull requests. By submitting a pull request, you represent that you have the right to contribute the submitted code and agree that your contribution will be licensed under the Apache License, Version 2.0, under which this project is distributed.

Optionally, if you wish, you may add your name and affiliation to the :doc:`contributor_list`. This list is maintained in the GitHub repository and is also displayed in the online documentation as a way to acknowledge those who have contributed to the project.
